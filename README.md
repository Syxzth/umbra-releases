# Umbra

Instaladores do Umbra para Windows. Baixe o `Umbra Setup x.y.z.exe` da versão mais nova em **Releases**.

Na primeira vez o Windows pode avisar "o Windows protegeu o computador" (o app ainda não tem certificado pago): clique em **Mais informações** e depois em **Executar assim mesmo**.

Depois de instalado, o Umbra se atualiza sozinho.
